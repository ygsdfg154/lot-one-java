### 3.3 生成后必做的调整
```
1. Controller 类上的 @RequestMapping 路径要与原 Go 路由一致
   原 Go: /api/system/user → Java: /api/system/user
2. 统一返回结果用 R<T>（lot-one-common 中定义）
   格式：{code:0, data:..., msg:"success"}
3. 分页查询用 PageResult<T>（与原 GVA 分页格式一致）
   格式：{list:[...], total:100, page:1, pageSize:10}
4. 实体类中 JSON 字段用 @TableField(typeHandler = JacksonTypeHandler.class)
5. 逻辑删除字段加 @TableLogic
```

### 4.1 统一返回结果 R.java
```java
package com.lotone.common.result;

import lombok.Data;
import java.io.Serializable;

@Data
public class R<T> implements Serializable {
    private Integer code;
    private T data;
    private String msg;

    public static <T> R<T> success() {
        R<T> r = new R<>();
        r.setCode(0);
        r.setMsg("success");
        return r;
    }

    public static <T> R<T> success(T data) {
        R<T> r = new R<>();
        r.setCode(0);
        r.setData(data);
        r.setMsg("success");
        return r;
    }

    public static <T> R<T> fail(String msg) {
        R<T> r = new R<>();
        r.setCode(7); // GVA 默认错误码
        r.setMsg(msg);
        return r;
    }

    public static <T> R<T> fail(Integer code, String msg) {
        R<T> r = new R<>();
        r.setCode(code);
        r.setMsg(msg);
        return r;
    }
}
```

## 五、登录与权限实现（P1 核心）

### 5.1 JWT 工具类
```java
package com.lotone.common.utils;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.security.Keys;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

import javax.crypto.SecretKey;
import java.nio.charset.StandardCharsets;
import java.util.Date;
import java.util.HashMap;
import java.util.Map;

@Component
public class JwtUtils {

    @Value("${jwt.signing-key}")
    private String signingKey;

    @Value("${jwt.expires-time}")
    private Long expiresTime;

    private SecretKey getKey() {
        return Keys.hmacShaKeyFor(signingKey.getBytes(StandardCharsets.UTF_8));
    }

    public String generateToken(Integer userId, String username) {
        Map<String, Object> claims = new HashMap<>();
        claims.put("userId", userId);
        claims.put("username", username);
        return Jwts.builder()
                .claims(claims)
                .issuedAt(new Date())
                .expiration(new Date(System.currentTimeMillis() + expiresTime * 1000))
                .signWith(getKey())
                .compact();
    }

    public Claims parseToken(String token) {
        return Jwts.parser()
                .verifyWith(getKey())
                .build()
                .parseSignedClaims(token)
                .getPayload();
    }
}
```

## 六、设备网关 Netty 实现（P5 核心）

### 6.1 Netty 服务启动类
```java
package com.lotone.iot.gateway.netty;

import io.netty.bootstrap.ServerBootstrap;
import io.netty.channel.ChannelFuture;
import io.netty.channel.ChannelInitializer;
import io.netty.channel.ChannelOption;
import io.netty.channel.EventLoopGroup;
import io.netty.channel.nio.NioEventLoopGroup;
import io.netty.channel.socket.SocketChannel;
import io.netty.channel.socket.nio.NioServerSocketChannel;
import io.netty.handler.timeout.IdleStateHandler;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.boot.CommandLineRunner;
import org.springframework.stereotype.Component;

@Slf4j
@Component
public class NettyTcpServer implements CommandLineRunner {

    @Value("${netty.tcp.port}")
    private int port;

    @Value("${netty.tcp.boss-threads}")
    private int bossThreads;

    @Value("${netty.tcp.worker-threads}")
    private int workerThreads;

    @Value("${netty.heartbeat.timeout-seconds}")
    private int heartbeatTimeout;

    @Override
    public void run(String... args) {
        EventLoopGroup bossGroup = new NioEventLoopGroup(bossThreads);
        EventLoopGroup workerGroup = new NioEventLoopGroup(workerThreads);
        try {
            ServerBootstrap bootstrap = new ServerBootstrap();
            bootstrap.group(bossGroup, workerGroup)
                    .channel(NioServerSocketChannel.class)
                    .option(ChannelOption.SO_BACKLOG, 1024)
                    .childOption(ChannelOption.SO_KEEPALIVE, true)
                    .childOption(ChannelOption.TCP_NODELAY, true)
                    .childHandler(new ChannelInitializer<SocketChannel>() {
                        @Override
                        protected void initChannel(SocketChannel ch) {
                            ch.pipeline()
                                    .addLast(new IdleStateHandler(heartbeatTimeout, 0, 0))
                                    .addLast(new Jt808FrameDecoder())  // 帧解码
                                    .addLast(new Jt808MessageDecoder()) // 消息解码
                                    .addLast(new Jt808MessageEncoder()) // 消息编码
                                    .addLast(new DeviceAuthHandler())    // 设备认证
                                    .addLast(new DeviceMessageHandler()); // 业务处理
                        }
                    });
            ChannelFuture future = bootstrap.bind(port).sync();
            log.info("Netty TCP 设备网关启动成功，端口：{}", port);
            future.channel().closeFuture().sync();
        } catch (InterruptedException e) {
            log.error("Netty 服务启动失败", e);
            Thread.currentThread().interrupt();
        } finally {
            bossGroup.shutdownGracefully();
            workerGroup.shutdownGracefully();
        }
    }
}
```

### 6.2 JT808 帧解码器
```java
package com.lotone.iot.gateway.netty.codec;

import com.lotone.protocol.jt808.Jt808Utils;
import io.netty.buffer.ByteBuf;
import io.netty.buffer.Unpooled;
import io.netty.channel.ChannelHandlerContext;
import io.netty.handler.codec.ByteToMessageDecoder;
import lombok.extern.slf4j.Slf4j;
import java.util.List;

@Slf4j
public class Jt808FrameDecoder extends ByteToMessageDecoder {

    private static final byte DELIMITER = 0x7E;

    @Override
    protected void decode(ChannelHandlerContext ctx, ByteBuf in, List<Object> out) {
        // 找到起始标志
        int startIndex = in.indexOf(in.readerIndex(), in.writerIndex(), DELIMITER);
        if (startIndex < 0) {
            in.clear();
            return;
        }
        // 跳过起始标志前的字节
        if (startIndex > in.readerIndex()) {
            in.skipBytes(startIndex - in.readerIndex());
        }
        // 找到结束标志
        int endIndex = in.indexOf(startIndex + 1, in.writerIndex(), DELIMITER);
        if (endIndex < 0) {
            // 不完整帧，等待更多数据
            return;
        }
        // 读取帧（包含首尾 0x7E）
        int frameLength = endIndex - startIndex + 1;
        ByteBuf frame = in.readBytes(frameLength);
        // 转义还原 + 校验
        ByteBuf payload = Jt808Utils.unescapeAndVerify(frame);
        if (payload != null) {
            out.add(payload);
        } else {
            log.warn("JT808 帧校验失败，丢弃");
        }
        frame.release();
    }
}
```

## 七、Kafka 消费者实现（P6 核心）

```java
package com.lotone.iot.worker.consumer;

import com.lotone.common.protocol.DeviceTelemetry;
import com.lotone.iot.worker.service.TelemetryProcessService;
import lombok.extern.slf4j.Slf4j;
import org.apache.kafka.clients.consumer.ConsumerRecord;
import org.springframework.kafka.annotation.KafkaListener;
import org.springframework.kafka.support.Acknowledgment;
import org.springframework.stereotype.Component;

import java.util.List;

@Slf4j
@Component
public class DeviceTelemetryConsumer {

    @Autowired
    private TelemetryProcessService telemetryProcessService;

    // 批量消费位置数据
    @KafkaListener(
            topics = "device-telemetry",
            groupId = "iot-worker-group",
            containerFactory = "batchFactory"
    )
    public void onTelemetry(List<ConsumerRecord<String, DeviceTelemetry>> records,
                             Acknowledgment ack) {
        try {
            for (ConsumerRecord<String, DeviceTelemetry> record : records) {
                DeviceTelemetry telemetry = record.value();
                // 1. 写入 MongoDB（最新位置）
                telemetryProcessService.saveToMongo(telemetry);
                // 2. 写入 TDengine（时序数据）
                telemetryProcessService.saveToTdengine(telemetry);
                // 3. 报警规则判断
                telemetryProcessService.checkAlarm(telemetry);
                // 4. 更新设备在线状态
                telemetryProcessService.updateDeviceStatus(telemetry);
            }
            // 处理成功后提交 offset
            ack.acknowledge();
        } catch (Exception e) {
            log.error("处理设备位置数据失败，记录数：{}", records.size(), e);
            // 不提交 offset，下次重试
            // 注意：生产环境应加入死信队列，避免无限重试
        }
    }
}
```

## 八、TDengine 写入实现（P6 核心）

```java
package com.lotone.iot.worker.service;

import com.lotone.common.protocol.DeviceTelemetry;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;

import javax.annotation.PostConstruct;
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.SQLException;
import java.util.List;

@Slf4j
@Service
public class TdengineService {

    @Value("${tdengine.url}")
    private String url;
    @Value("${tdengine.username}")
    private String username;
    @Value("${tdengine.password}")
    private String password;

    private Connection connection;

    @PostConstruct
    public void init() {
        try {
            Class.forName("com.taosdata.jdbc.rs.RestfulDriver");
            connection = DriverManager.getConnection(url, username, password);
            // 创建超级表（如果不存在）
            createSuperTable();
        } catch (Exception e) {
            log.error("TDengine 初始化失败", e);
        }
    }

    private void createSuperTable() throws SQLException {
        String sql = "CREATE STABLE IF NOT EXISTS device_telemetry (" +
                "ts TIMESTAMP, " +
                "longitude DOUBLE, " +
                "latitude DOUBLE, " +
                "speed FLOAT, " +
                "direction FLOAT, " +
                "altitude INT, " +
                "status INT" +
                ") TAGS (device_id NCHAR(64))";
        try (PreparedStatement ps = connection.prepareStatement(sql)) {
            ps.execute();
        }
    }

    // 批量写入
    public void batchInsert(List<DeviceTelemetry> list) {
        if (list == null || list.isEmpty()) return;
        // 按 deviceId 分组，每个子表一条 INSERT
        // TDengine 支持一条 SQL 插入多个子表：INSERT INTO t1 USING st1 TAGS(...) VALUES (...), (...)
        StringBuilder sql = new StringBuilder("INSERT INTO ");
        for (DeviceTelemetry t : list) {
            String subTable = "device_" + t.getDeviceId().replaceAll("[^a-zA-Z0-9]", "_");
            sql.append(subTable)
               .append(" USING device_telemetry TAGS('").append(t.getDeviceId()).append("') ")
               .append("VALUES (").append(t.getTimestamp()).append(", ")
               .append(t.getLongitude()).append(", ")
               .append(t.getLatitude()).append(", ")
               .append(t.getSpeed()).append(", ")
               .append(t.getDirection()).append(", ")
               .append(t.getAltitude()).append(", ")
               .append(t.getStatus()).append(") ");
        }
        try (PreparedStatement ps = connection.prepareStatement(sql.toString())) {
            ps.execute();
        } catch (SQLException e) {
            log.error("TDengine 批量写入失败", e);
        }
    }
}
```

## 十、常见问题排查

### Q1: 编译报错找不到符号
```
原因：Lombok 注解处理器未启用
解决：Settings → Build → Compiler → Annotation Processors → 勾选 Enable
```

### Q2: 启动报错数据源连接失败
```
原因：Nacos 配置未加载或数据库未启动
解决：
1. 检查 bootstrap.yml 中 Nacos 地址是否正确
2. 检查 Nacos 中是否有对应服务的配置
3. 检查 MySQL/Redis 是否启动
```

### Q3: 前端登录后请求 401
```
原因：Token 名称或请求头不一致
解决：
1. 原 GVA 用 x-token 头，Sa-Token 默认也是 token-name: x-token
2. 检查前端请求拦截器是否正确设置 x-token
3. 检查 Sa-Token 拦截器是否排除了登录接口
```

### Q4: 设备连不上网关
```
原因：Netty 端口未开放或防火墙拦截
解决：
1. 检查 netty.tcp.port 配置（默认8083）
2. 检查防火墙是否开放该端口
3. 用 telnet 测试：telnet localhost 8083
4. 查看网关日志是否有连接记录
```

### Q5: Kafka 消费不到消息
```
原因：topic 不存在或消费者组配置错误
解决：
1. 检查 topic 是否创建：kafka-topics --list --bootstrap-server localhost:9092
2. 检查消费者组是否正确
3. 检查生产者是否成功发送消息
4. 查看 Kafka 消费者日志
```
